# 当代人工智能实验二：搜索算法

## 实验简介

本实验实现 **A\*** 搜索与 **Minimax / Alpha-Beta 剪枝** 博弈搜索，完成四道题目：

| 题目 | 内容 | 方法 | 测试用例输出 |
| --- | --- | --- | --- |
| 题目一 | 迷宫寻路 | A\*，四方向，代价 1，曼哈顿启发 | 长度为 8 的最短路径 |
| 题目二 | 加权地形 | A\*，进入格子代价=地形权值，进入 E 代价 0 | `7` |
| 题目三 | 博弈树最佳得分 | Alpha-Beta（从左到右），另实现 Minimax 对照 | `5` |
| 题目四 | 竞争环境宝藏分配 | A\* 距离矩阵 + Minimax / Alpha-Beta | H=2：`T2, -1`；H=4：`T3, 3` |

并在此基础上完成了启发函数、访问顺序、搜索深度等对照实验，以及“收益排序 + 置换表”的优化拓展。

## 主要实验结论

- **启发函数**：题目一中曼哈顿启发把扩展节点从 17 降到 14；在 100×100 随机迷宫上从 6800 降到 1183（约 5.7 倍），路径仍最优。加权 A\*（w=2）扩展仅 361，但路径平均长 13%。
- **题目二可采纳性**：因进入 E 免费，直接用曼哈顿距离会在 E 的邻居处高估 1，严格说不可采纳；本实现采用 `h=(d-1)·w_min`，可采纳且一致。实验与分析表明直接曼哈顿在本题仍能得到最优解（高估量对所有非终点节点是同一常数），而 `d×平均权值` 这种非均匀高估在 200 个随机地形中有 197 个得到非最优解。
- **访问顺序**：随机博弈树（b=5, d=6）上 Minimax 评估 15625 个叶子，Alpha-Beta 随机序 2384，最优序 249（与 Knuth-Moore 理论值一致），最差序 12970。
- **题目四**：收益排序把 H=4 的访问状态数从 47（默认序）降到 37；H≤3 时 A 选 T2，H=4 时改选 T3（抢走 B 最近的宝藏，并迫使 B 最后去拿远处的 T4，收益 -5）。
- **拓展**：8 宝藏 15×15 地图、H=8 时，Minimax 109601 个状态 → Alpha-Beta 14510 → 收益排序 3832 → 收益排序+“分数无关”置换表 1974，结果完全一致。
